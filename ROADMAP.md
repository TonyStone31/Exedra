# Roadmap

Where Exedra stands and what comes next. Dates are not promised.

## Done

- The shared core: members, sign-in, roles, the guard, the admin page
  and backups. It builds and runs with no part at all.
- The chat, with private conversations, the IRC side and Web Push.
- The wiki.
- The forum: boards, topics and posts with moderation, search, read
  marks and files in posts.
- The switch: each part turned on or off from the config file or the
  admin page.
- MariaDB, MySQL, PostgreSQL and SQLite.
- The source in this repository, and [INSTALL.md](INSTALL.md).

## Next

- A release for Linux x86_64 that needs no compiler: the program, the
  page files, the sample config and an install script.
- A Docker compose file.
- Exedra Desktop in its own repository, with release builds for
  Linux, Windows and macOS.
- Forum mentions, following a topic, and mail about replies.

## Later

- A discussion under each wiki page, when the chat is on.
- An importer for MediaWiki dumps, and one for Simple Machines Forum.
- Running as a CGI program on shared hosting, with SQLite.
